# 色彩検定1級2次 慣用色名・トーントレーニング

色彩検定1級2次の慣用色名とPCCSの色票選択を練習する、iPhone Safariで使いやすいPWA学習アプリです。

PWAは「ホーム画面に追加してアプリのように使えるWebアプリ」のことです。

## セットアップ方法

初回だけ、作業フォルダで依存関係を入れます。

```bash
npm install
```

## CSVの置き場所

問題CSVは以下に置きます。

```text
public/data/questions.csv
```

CSVヘッダーは以下です。

```text
question_id,mode,prompt,choice_a,choice_b,choice_c,choice_d,answer,explanation,wrong_choice_notes,tags,difficulty
```

`tags` は `赤系|和色` のように `|` 区切りで書きます。`difficulty` は `1` から `3` です。


## 問題を追加する方法

問題を増やすときは、以下のCSVファイルに1行ずつ追加します。CSVは「カンマ区切りの表データ」のことです。

```text
public/data/questions.csv
```

1行が1問です。追加するときは、既存のサンプル行をコピーして下に貼り付け、内容を変えるのが安全です。

- `question_id`: 問題ごとの名前です。重複しないように `color-001` のように付けます。
- `mode`: 出題モード名です。例: `慣用色名`
- `prompt`: 画面に出る問題文です。
- `choice_a` から `choice_d`: 4つの選択肢です。
- `answer`: 正解です。選択肢のどれかと完全に同じ文字にします。
- `explanation`: 回答後に表示する解説です。
- `wrong_choice_notes`: 間違い選択肢の補足です。
- `tags`: `赤系|和色` のように `|` で区切ります。
- `difficulty`: 難易度です。`1` が易しめ、`3` が難しめです。

文字の中にカンマ `,` を入れたい場合は、その項目全体を `"淡い赤, 紫みを含む"` のように半角ダブルクォートで囲みます。迷う場合は、カンマを使わず `・` や `、` にすると安全です。

追加後はMacで `npm run dev` を起動し、アプリの設定画面から「CSV再読み込み」を押して確認します。

## 開発サーバー起動方法

```bash
npm run dev
```

表示されたURLをブラウザで開きます。通常は以下です。

```text
http://localhost:5173/
```

## ビルド方法

公開前やエラー確認には以下を実行します。

```bash
npm run build
```

成功すると `dist/` に完成ファイルが作られます。

## iPhoneで使う方法

### GitHub Pagesからホーム画面に追加する場合

公開URLは以下です。

```text
https://sibzak-kaszuq-1javha.github.io/color-test/
```

1. 初回だけiPhoneをWi-Fiに接続します。
2. Safariで上の公開URLを開き、問題数が表示されることを確認します。
3. Safariの共有ボタンから「ホーム画面に追加」を選びます。
4. 追加された「色彩検定」を通信中に一度開きます。
5. 機内モードにしてWi-Fiも切り、ホーム画面からもう一度開いて確認します。

ホーム画面へ追加したあとは、保存済みの画面と問題を通信なしでも利用できます。問題を更新したときだけWi-Fiへ接続し、アプリを開き直してください。

### 同じWi-Fi内で確認する場合

開発中にiPhoneで確認する場合は、Macを簡易サーバーとして使います。サーバーは「同じWi-Fi内だけで見られる表示用の窓口」です。

1. MacとiPhoneを同じWi-Fiに接続します。
2. Macのターミナルで以下を実行します。

```bash
npm run dev -- --host 0.0.0.0
```

3. ターミナルに表示される `Network:` のURLを確認します。例: `http://192.168.1.10:5173/`
4. そのURLをiPhoneのSafariで開きます。
5. アプリのように使いたい場合は、Safariの共有ボタンから「ホーム画面に追加」を選びます。

注意: この方法ではMac側のターミナルを止めると、iPhoneからも開けなくなります。iPhoneもMacと同じWi-Fi内にいる必要があります。

### 出先で使う場合

出先で使う場合は、`npm run dev` ではなくGitHub Pagesなどに公開して使います。GitHub Pagesは「GitHub上のファイルをWebサイトとして公開する仕組み」です。

一度公開URLをSafariで開いて「ホーム画面に追加」しておけば、通常のWebアプリとして外出先でも開けます。PWAの保存が効いている範囲では、通信が不安定な場所でも表示できる場合があります。

学習履歴はブラウザ内の `localStorage` に保存されます。`localStorage` は「そのブラウザの中だけに保存される小さな保管場所」です。外部サーバーへ送信しません。

## 主な機能

- 1問ずつ出題
- 4択回答
- ホームから苦手分野の練習、またはトーン名から色票を選ぶ練習に直接移動
- 正誤判定
- 解説表示
- 回答履歴保存
- 間違えた問題の復習
- タグ別・difficulty別の成績表示
- 学習履歴のエクスポート、インポート、リセット
- CSV再読み込み

## 出題の進み方

- 学習開始時に未回答の問題を優先し、その回の出題順を固定します。
- 選択肢は学習・復習の開始ごとにランダムに並べます。回答や「要チェック」の操作では並びを変えません。
- 左上は今回の問題番号です。「次の問題へ」で1つ進み、最後は完了画面になります。
- 復習も開始時の対象を一巡します。途中の回答やチェック解除で問題が飛ぶことはありません。完了後の「復習対象を更新する」で最新の対象を取得します。
- 正誤は選択肢の文字で判定し、回答後の色見本も選択肢と同じ順で表示します。
- トーン問題は、回答前に番号と色票、回答後にトーン名とPCCS記号を表示します。画面用の近似色を使っています。
- 問題文の限定条件を見直した一覧と確認資料は [問題文の見直し](docs/question-review.md) に記載しています。

## 動作確認

Node.js 22.6以上を使い、ターミナルで `npm test` と `npm run build` を実行します。
`npm run dev` で表示されるURLをブラウザで開き、「学習開始」から数問回答してください。
左上が1→2→3と進み、正解が先頭に固定されず、回答後も同じ問題の解説が出れば正常です。
同じ正解位置が偶然続く場合はあります。

今回の修正前ファイルは `backups/quiz-fixes.local-20260918-162441/` に保存しています。
戻す場合は修正を取り消すGitの履歴を作成するか、このバックアップから対象ファイルを復元します。
学習履歴はブラウザに別保存されているため、ファイルを戻す際に履歴をリセットする必要はありません。

## 戻し方

作業を戻したい場合は、GitHub上の直前のコミットに戻せます。学習履歴だけを戻したい場合は、設定画面でリセットできます。リセット前にエクスポートしておくと、あとでインポートできます。
